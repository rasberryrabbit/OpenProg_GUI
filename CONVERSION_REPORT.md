## Conversion approach

### GUI (Glade → LFM)

Each GTK widget class is mapped to its closest LCL counterpart:

- `GtkWindow` → `TForm`
- `GtkBox` (vertical/horizontal) → `TPanel` with `Align`/`ChildSizing`
- `GtkButton` → `TButton`; `GtkToolButton` → `TToolButton`
- `GtkLabel` → `TLabel`; `GtkEntry` → `TEdit`; `GtkSpinButton` → `TSpinEdit`
- `GtkComboBoxText` → `TComboBox`
- `GtkTextView` → `TMemo` (inside `GtkScrolledWindow` → `TScrollBox`)
- `GtkNotebook` → `TPageControl` (children become `TTabSheet`s)
- `GtkCheckButton`/`GtkRadioButton`/`GtkToggleButton` → `TCheckBox`/`TRadioButton`/`TSpeedButton`
- `GtkStatusbar` → `TStatusBar`
- `GtkTreeView` → `TListView` (columns added at runtime)
- `GtkAdjustment` objects are inlined into their owning `TSpinEdit`/`TTrackBar`

### Signals → Events

GTK signal handlers are connected to LCL events in the LFM:

- `clicked` → `OnClick`
- `toggled` → `OnClick` (for `TSpeedButton`)
- `changed` → `OnChange`
- `value-changed` → `OnChange`
- `destroy` → `OnClose`
- `key-press-event` → `OnKeyDown`
- `button-press-event` → `OnMouseDown`

Handler names are preserved verbatim so the C source bodies can be ported 1:1.

### C → Pascal

Each `.c` file becomes one `.pas` unit. The translator:

1. Extracts function definitions and emits Pascal `procedure`/`function` signatures.
2. Translates common GTK calls (`gtk_button_set_label`, `gtk_spin_button_get_value_as_int`, ...) to LCL equivalents (`Caption :=`, `Value`, ...).
3. Translates libc helpers (`sprintf`→`Format`, `strcmp`→`AnsiCompareStr`, `strlen`→`Length`, ...).
4. Translates control flow (`if`/`for`/`while`/`switch`/`return`).
5. Anything it cannot confidently translate is wrapped in a `(* TODO gtk2laz: ... *)` comment block so the project still compiles once the offending statement is replaced by a stub.

- **Resource paths**: `/res/foo.png` from `glib-compile-resources` → load via `TResourceStream` or copy into the executable directory and `TImage.Picture.LoadFromFile`.
